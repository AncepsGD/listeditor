Score 0
1. M = highest submitted run's End %; the attempt that first reached M is the “peak run”
2. Qualifying runs = any run with End % ≥ M × (Filler Threshold/100); low-value filler runs still count toward penalty
3. If fewer than 2 runs qualify → Score = M × peak coverage (if coverage enabled, else just M) – a personal best, not a consistency claim
4. Coverage = (End − Start) / End (0–1). Discounted if enabled – applies to the peak run too.
5. Otherwise, for each other qualifying run: contribution = Weight × (run/M)^k × decay^(rank−2) × orderFactor × coverage
6. Order factor = Pre-Peak Multiplier if before peak, Post-Peak Multiplier if at/after it
7. Score = peak contribution + Σ other contributions
8. Combined Level Factor = product of (difficulty/100)^(coverage/100) for each segment
9. Gate A: Score ≥ Baseline × (1 + Margin/100)^k × Combined Level Factor
10. Gate B: Score > Current Achievement Score
11. Accepted only if both gates pass
